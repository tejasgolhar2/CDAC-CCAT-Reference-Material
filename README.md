
# CDAC CCAT Reference Material

This repository contains comprehensive study materials and references for the CDAC-CCAT (Centre for Development of Advanced Computing - Common Computing Admission Test) examination. The content is organized into multiple sections covering all major topics of the exam syllabus.

## Repository Structure

### Section A - Quantitative Aptitude
- **References**
  - RS Aggrawal Quantitative Aptitude
  - Computer Fundamentals by Pradeep Sinha
- Study materials and practice problems
- Screenshots and visual aids for better understanding

### Section B - Coding and Programming
- **References and Study Materials for:**
  - C Programming
  - Data Structures
  - Object-Oriented Programming Concepts
  - Operating Systems
  - Basics of Big Data and Artificial Intelligence

### Section C - MPMC and Computer Architecture & Organization
- **Microprocessors and Computer Architecture**
  - Digital Electronics
  - Computer Architecture fundamentals
  - Microprocessors study material

### Previous Year Questions (PYQ)
- Important MCQs compilation
- Year-wise question papers (2017-2019)
- Practice materials and solutions

## Purpose
This repository serves as a centralized resource for CDAC-CCAT exam preparation, offering:
- Structured study materials
- Previous year questions
- Important concepts and references
- Practice resources

## Note
This is a reference material repository. Please use it alongside official CDAC-CCAT guidelines and materials for comprehensive exam preparation.
